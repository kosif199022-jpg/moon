# Security policy

Do not open public issues containing client records, financial statements, access tokens, passwords, licensed standards, or audit evidence.

Report a vulnerability privately to the repository owner. Include the affected commit, reproduction steps, impact, and a minimal proof of concept. Do not retain or redistribute client data discovered during testing.

The browser demo stores engagement data locally. It is not a production multi-tenant service and must not be used with real confidential client data until authentication, tenant isolation, encrypted storage, malware scanning, retention controls, and deployment hardening are completed and independently reviewed.
